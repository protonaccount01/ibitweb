🔐 Admin Password Hash Generator

এটা সম্পূর্ণ অফলাইনে, শুধু তোমার ব্রাউজারের ভেতরেই চলে (Web Crypto API দিয়ে) — কোথাও কিছু পাঠায় না, কোনো ইন্টারনেট/সার্ভার লাগে না। ইন্টারনেট বন্ধ করে দিয়েও চালাতে পারো, নিশ্চিন্তে।

ADMIN_USERNAME (Cloudflare env var-এ এটা বসাও)
ADMIN_PASSWORD_HASH (Cloudflare env var-এ এটা বসাও)
⚠️ এই পেজে যা দেখাচ্ছে তার মধ্যে শুধু হ্যাশটা Cloudflare-এর env var-এ বসাবে। আসল পাসওয়ার্ডটা (যেটা উপরে টাইপ করলে) তুমি নিজে মনে রাখবে — এটাই তুমি admin লগইন ফর্মে টাইপ করবে প্রতিবার, হ্যাশটা না।
